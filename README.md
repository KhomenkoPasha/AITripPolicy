# AITripPolicy
Public privacy policy and account/data deletion information for **AITripPlanner** (`khom.pavlo.aitripplanner`), by Pavlo Khomenko.

## Published pages
- [Privacy policy](https://khomenkopasha.github.io/AITripPolicy/)
- [Account deletion requests](https://khomenkopasha.github.io/AITripPolicy/delete-account.html)
- Ukrainian: `privacy-uk.html`, `delete-account-uk.html`
- Russian: `privacy-ru.html`, `delete-account-ru.html`

Static HTML and CSS, inspired by [MemesPolicy](https://github.com/KhomenkoPasha/MemesPolicy). All content works without JavaScript, cookies or browser storage. There are no added analytics, external fonts or tracking scripts.

## Deployment
GitHub Pages: deploy from `main`, root (`/`). No build dependencies.

## Maintenance
Effective date: 2026-09-21. Update all three translations together when data handling changes.
Deletion requests go to hompavlik@gmail.com and require manual processing by the developer; this site does not automate server-account deletion. The Android app still needs an in-app account-deletion request path and a privacy-policy link before its full Google Play data-policy setup is complete.
